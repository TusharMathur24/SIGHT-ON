# Sight On: Blind Aid Bot

## Overview

**Sight On** is an AI-powered assistive device designed to aid visually impaired individuals in navigating their surroundings safely and independently. Using real-time **image recognition, object detection, and distance measurement**, this project enhances spatial awareness and helps users interact effectively with their environment.

## Features

- **Real-time Object Detection:** Identifies objects in the user's surroundings using machine learning.
- **Image Recognition:** Recognizes common objects and obstacles to assist navigation.
- **Distance Calculation:** Measures the distance between the user and detected objects for better spatial awareness.
- **Adaptive Learning System:** Customizes alerts and recognition based on user behavior.
- **Wearable Design:** Designed for portability and ease of use.
- **Emergency SOS Feature:** Sends alerts in case of falls or emergencies.

## Technologies Used

- **Python** - Core programming language for development.
- **OpenCV** - Image processing and real-time object detection.
- **YOLOv8** - Deep learning model for accurate object detection.
- **MediaPipe** - Hand gesture recognition and tracking.
- **NumPy & Pandas** - Data processing and management.
- **Flask** - Backend framework for potential web-based integration.
- **Arduino/Raspberry Pi (Optional)** - For hardware-based deployment.

## Installation

### Prerequisites:
- Python 3.8+

- TensorFlow (if required)

## Usage
- Launch the program and let it scan the environment using a connected camera.
- The bot provides **real-time voice feedback** about detected objects and their distances.
- Future enhancements include **gesture-based controls** and **integration with smart city infrastructure**.

## Future Scope

- **Cloud Connectivity** for storing user preferences and improving AI learning.
